# Elokuvaprojekti

Tekijät: __Mikael Luosola, Ntarlin Bempetsi__

Elokuvaprojekti on tekstipohjainen Python‑ohjelma, jonka avulla voit pitää omaa elokuvalistaa.

## Tärkeimmät toiminnot

- Elokuvien lisääminen  
- Elokuvien katsominen  
- Tietyn elokuvan hakeminen  
- Elokuvien tietojen muokkaus  
- Elokuvien poistaminen

## Käynnistysohjeet

Ohjelman käynnistäminen on yksinkertaista: aja sovellus komennolla

```python
python elokuvalista.py
```

## Data ja tallennus

*Tiedot tallennetaan movies.json-tiedostoon.*

Yhdestä elokuvasta tallennetaan esimerkiksi nimi, genre, julkaisuvuosi, arvosana, katsottu‑tila ja muistiinpanot.

## Parityöskentely

Käytimme Driver‑Navigator‑mallia, vaihdoimme rooleja työn aikana, ja molemmat osallistuivat suunnitteluun, koodaukseen, testaukseen sekä esityksen tekemiseen.
